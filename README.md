# Run and deploy your Biterush app

This contains everything you need to run your app locally.


## Run Locally
**Prerequisites:**  Node.js v20

1. Install dependencies:
   `npm install`
2. Set the required environment variables in [.env.local](.env.local) file:
   - `MONGODB_URI`
   - `JWT_SECRET`
3. Run the app:
   `npm run dev`
4. It'll run on default 3000 port.
